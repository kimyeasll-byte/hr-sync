## 2. 관리자 매뉴얼 1: 원터치 종합 입사 자동화 (5-in-1 Pipeline)

### 2.1 주요 기능
신규 입사자의 기본 인적 사항을 입력하고 **[⚡ 원터치 입사 자동화 일괄 실행]**을 1회 클릭하는 것만으로 다음 5개 전산/인사 업무가 실시간 자동 실행됩니다:
1. 사내 ERP / 그룹웨어(다우오피스) 계정 및 고유 사번 자동 채번
2. 직무/부서 맞춤 IT 장비 3종(노트북+듀얼모니터+출입증) 자동 배정 및 고정 IP 채번
3. 온보딩 필수 체크리스트 자동 동기화 & 7단계 마일스톤 캘린더 등록
4. 신입사원 개인 메일로 모바일 포털 링크 및 웰컴 안내장 실시간 발송
5. ITGC 내부통제 감사 로그 영구 기록 및 입사 확인서 번호 생성

### 2.2 단계별 실행 방법
1. 대시보드 상단 메뉴에서 **[신규 입사자 관리] ➔ [원터치 입사 자동화]** 서브 탭을 선택합니다.
2. 빠른 시연을 원할 경우 우측 상단의 **빠른 시연 프리셋 버튼**을 클릭합니다:
   - `🚀 연구소 HW개발`: 홍길동 / 선임연구원 / 수원1 사업장 / 갤럭시북4 Pro 배정
   - `💼 경영지원 인사`: 김민서 / 대리 / 수원1 사업장 / LG 그램 15 배정
   - `🌐 기술영업(서울)`: 박지훈 / 과장 / 서울 본사 / LG 그램 15 배정
3. 입사자 성명, 소속 부서, 직급, 직책, 근무 사업장(수원/서울), 출근 예정일, 개인 이메일을 확인합니다.
4. **[⚡ 원터치 입사 자동화 일괄 실행]** 버튼을 클릭합니다.
5. 화면에 5단계 순차 하이테크 실행 콘솔이 작동하며, 각 단계가 순서대로 완료됩니다.
6. 완료 후 하단의 결과 카드에서 다음 작업을 즉시 수행할 수 있습니다:
   - **[📱 신입사원 모바일 포털 바로 열기]**: 신입사원이 보게 될 모바일 웹 화면 새 탭 열기
   - **[🖨️ ITGC 입사 확인서(A4) 인쇄/PDF]**: 공식 증빙서 인쇄
   - **[📅 7대 마일스톤 여정 보기]**: 상세 진행률 및 D-Day 타임라인 확인
   - **[💻 IT 자산 대장 확인]**: 방금 배정된 장비 3건 확인

## 3. 신규 입사자 매뉴얼: 모바일 셀프 온보딩 포털 사용법

신규 입사자는 첫 출근 전 안내 메일에 포함된 전용 URL(`/onboard/portal/[token]`)을 통해 모바일 포털에 접속합니다.

### 3.1 주요 이용 절차
1. **첫 출근 카운트다운 & 사업장 길안내 확인**:
   - 첫 출근 D-Day 확인
   - [네이버 지도 길찾기] 또는 [카카오맵] 버튼을 터치하여 수원 영통 사업장 / 서울 가산 본사 대중교통 및 주차 안내 확인
2. **사원증 지정 사진관 안내 확인**:
   - 파워넷 공식 제휴 사진관인 **[패밀리포토하우스]** 네이버 지도 링크 확인
   - "사원증 실물 제작은 사진 촬영 및 접수 후 약 2주 소요되며, 제작 전까지 임시 출입증이 발급됩니다." 안내문 확인
3. **사원증 프로필 사진 촬영 및 접수**:
   - 모바일 카메라로 직접 촬영하거나 갤러리에서 증명사진 업로드
   - 사원증 목걸이형 시뮬레이터로 출력 시안 실시간 확인
4. **5대 필수 서류/준비물 체크리스트 점검**:
   - 주민등록등본, 급여통장 사본, 최종학력증명서, 신분증, 개인 텀블러 등 체크
5. **(주)파워넷 복리후생 가이드 탐색**:
   - 생활안정/주거, 건강/의료, 자기개발/교육, 여가/휴식 4개 카테고리의 12대 복지 제도 확인
6. **입사 각오 작성 및 [온보딩 준비 전송하기] 터치**:
   - 한 줄 각오 입력 후 제출 시 인사팀 관리자 대시보드에 실시간 전송 완료

## 4. 관리자 매뉴얼 2: 온보딩 접수 현황 검토 & 사원증 발주

### 4.1 포털 접수 데이터 확인 방법
1. 대시보드 상단 메뉴에서 **[신규 입사자 관리] ➔ [온보딩 여정 (D-Day)]** 서브 탭으로 이동합니다.
2. 좌측 입사자 목록에서 `✨ 포털 접수 완료` 뱃지가 붙은 직원을 클릭합니다.
3. 상단에 렌더링되는 **[신입사원 온보딩 포털 접수 현황]** 카드에서 다음을 확인합니다:
   - 신입사원이 업로드한 사원증 프로필 사진 미리보기
   - 신입사원이 작성한 입사 각오 및 한마디
   - 5대 서류/준비물 체크리스트(✔/○) 상태
4. **[사원증 원본 사진 다운로드]** 버튼을 클릭하여 고화질 원본 사진을 PC에 저장한 후 에스원(S1) 출입증 제작 업체로 발주합니다.

## 5. 관리자 매뉴얼 3: 회차별 펄스 서베이 & AI 피플 애널리틱스 분석

신입사원의 조기 퇴사는 주로 1~3개월 차의 조직 적응 실패에서 발생합니다. HR Sync는 4단계 회차별 마이크로 설문과 AI 분석을 제공합니다.

### 5.1 설문 주기 및 회차별 질문 구조
* **1개월차 (D+30)**: 초기 업무 난이도/업무량, 멘토·팀원 소통 분위기, IT 장비·인프라 지원
* **3개월차 (D+90)**: 직무 R&R/목표 명확성, 부서 간 협업 원활성, 업무 자율성/주도권
* **6개월차 (D+180)**: 직무 전문성·역량 성장 체감, 성과 피드백·인정, 업무 몰입도·워라밸
* **1년차 (D+365)**: 중장기 커리어 비전, 평가/보상 만족도, 지인 추천 의향(eNPS)

### 5.2 AI 조기퇴사 위험 신호(Flag) 분석 확인
1. 관리자 대시보드 온보딩 상세 뷰의 **[AI 피플 애널리틱스]** 카드를 확인합니다.
2. 3단계 위험 신호:
   - `🚨 Red Flag (고위험군)`: 즉각적인 인사팀 1:1 케어 면담 및 부서 배치 조정 필요
   - `⚠️ Yellow Flag (주의군)`: 멘토링 커피챗 및 고충 모니터링 권장
   - `✨ Green Flag (안정군)`: 안정적인 조직 몰입 및 성장 지원
3. AI 진단 의견과 핵심 키워드, 자동 도출된 실행 권고사항(Action Plan)을 검토합니다.
4. **[1:1 긴급 케어 면담 예약]** 또는 **[멘토 커피챗 알림 발송]** 원클릭 버튼을 눌러 적기에 후속 조치를 진행합니다.

## 6. 관리자 매뉴얼 4: IT 자산 대장 및 엑셀(CSV) 일괄 관리

### 6.1 IT 자산 대장 조회 및 필터링
1. 상단 대메뉴에서 **[IT 자산 관리]** 탭을 클릭합니다.
2. 상단 요약 카드에서 총 보유 자산, 정상 지급(대여 중), 회수 필요, 폐기 대기 현황을 확인합니다.
3. 검색창을 통해 직원명, 부서명, 모델명, 시리얼, 고정 IP로 실시간 필터링합니다.

### 6.2 엑셀 일괄 등록 (Bulk CSV Import)
1. 우측 상단의 **[📥 엑셀 표준 서식 다운로드]** 버튼을 눌러 UTF-8 BOM 지원 양식을 받습니다.
2. 사내 전산 자산 목록을 서식에 맞추어 작성합니다.
3. **[📤 엑셀 일괄 등록]** 버튼을 클릭하여 CSV 파일을 업로드합니다.
4. 유효성 검사 미리보기 모달에서 정상 데이터(✔)와 오류 데이터(⚠)를 검토 후 **[N건 일괄 등록 확정]**을 클릭합니다.

### 6.3 자산 원장 엑셀 내보내기
* **[📊 엑셀 다운로드]** 버튼을 클릭하면 한글 깨짐 없이 현재 자산 목록 전체가 CSV로 즉시 다운로드됩니다.

## 7. 관리자 매뉴얼 5: 원터치 종합 퇴사 권한 회수 및 자산 정산

### 7.1 원터치 즉시 퇴사 처리 (Instant Cutoff)
1. 상단 대메뉴에서 **[퇴사자 권한 회수]** 탭을 클릭합니다.
2. 검색창에서 퇴사 처리할 임직원을 클릭하여 선택합니다.
3. 하단에 조회되는 **[보유 IT 자산 정산 대상]** 목록에서 노트북, 모니터, 고정 IP, 출입증 현황을 확인합니다.
4. **[🚨 원터치 종합 퇴사 즉시 실행]** 버튼을 클릭합니다.
5. 시스템이 즉시 다음을 처리합니다:
   - 그룹웨어/사내메일 계정 영구 잠금 및 활성 SSO 세션 강제 만료
   - 사내 ERP/MES/VPN 접근 권한 일괄 박탈
   - 보유 IT 자산 전체 `RETURNED(반납 완료)` 처리
   - 에스원(S1) 출입 권한 영구 파기
6. 처리 완료 후 **[🖨️ ITGC 퇴사 확인서(A4) 즉시 인쇄/PDF]**를 클릭하여 서명용 증빙 문서를 발급합니다.

### 7.2 퇴사일 예약 (Scheduled Cutoff)
* 퇴사 예정일자를 선택한 뒤 **[📅 퇴사일 예약 (D+1 자동 차단)]**을 누르면 익일 자동 차단 대기 상태로 등록되며 자산은 `PENDING_RETURN`으로 설정됩니다.

## 8. 관리자 매뉴얼 6: ITGC 내부통제 감사 로그 및 증빙서 출력

### 8.1 감사 로그 조회 및 엑셀 다운로드
1. 상단 대메뉴에서 **[감사 로그 (ITGC)]** 탭을 클릭합니다.
2. 최근 3년간 보존되는 입사 세팅, 퇴사 차단, 포털 접수, 설문 제출 등의 변경 이력을 실시간 검색/조회합니다.
3. **[ITGC 엑셀(CSV) 다운로드]** 버튼을 클릭하여 외부 회계감사 증빙용 원장을 다운로드합니다.

### 8.2 A4 공식 확인서 인쇄/PDF 보존
* 각 작업 항목 우측의 **[증빙서 출력]** 버튼을 누르면 내부회계관리제도 규격의 단 1장 독립 인쇄 팝업이 호출되며 인쇄 또는 PDF 저장이 가능합니다.
