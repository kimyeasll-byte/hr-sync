# 3. 불편함 목록

## 이번 서비스에서 해결할 불편함 (TO-BE)
1. **수기 계정 생성 (입사)**: 그룹웨어, ERP 등 각기 다른 시스템에 일일이 관리자로 접속해서 신규 입사자의 계정을 반복해서 만들어야 하는 번거로움.
2. **소프트웨어 수동 설치 (입사)**: PC를 초기화한 후 필수 프로그램을 일일이 설치하고 네트워크(고정 IP)를 직접 설정해야 하는 긴 작업 시간.
3. **권한 회수 누락 (퇴사)**: 사람이 날짜(D+1)를 일일이 기억하고 챙기다 보니 바쁠 때 계정 삭제를 깜빡하는 예외 상황.
4. **수기 권한 회수 작업 (퇴사)**: 각 시스템마다 관리자 페이지에 접속해 일일이 퇴사자 계정을 찾아 삭제해야 하는 반복 작업.

## 이번 서비스에서 해결하지 않을 불편함 (사람이 계속 할 일)
1. **물리적인 기기 준비 및 회수**: 기존 자리에서 PC 선을 꽂고 초기화를 진행하는 기초 작업이나, 퇴사 당일에 PC와 사원증을 손으로 직접 반납받는 물리적 작업.
2. **외부 업체 소통**: 첫날 사진 촬영을 안내하고, 에스원과 문구점에 실물 사원증 및 명함을 신청하여 전달하는 일.
3. **권한 회수 최종 검증 (퇴사)**: 시스템이 D+1일에 알아서 계정을 삭제하더라도, 실제로 모든 권한이 안전하고 완벽하게 회수되었는지 관리자가 직접 화면을 보고 눈으로 최종 점검하고 확인하는 역할.
