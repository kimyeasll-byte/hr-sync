# 5. 화면 검토 판단 기준 (인수 조건)

화면과 사용 흐름이 맞게 나왔는지 판단할 때, 아래의 질문들에 "그렇다"고 답할 수 있어야 합니다.

1. **입사자 정보 통합 입력**: 새 서비스 화면에서 신규 입사자의 정보를 한 번만 입력하고 저장할 수 있는가?
2. **계정 연동 확인**: 정보를 저장했을 때 연동된 다른 시스템들에 계정이 올바르게 생성되었다는 것을 한눈에 확인할 수 있는가?
3. **PC 자동 세팅 연동**: PC 자동 세팅 버튼을 누르면, 프로그램 설치 및 방화벽/IP 설정 명령이 전달되고 진행 상태를 확인할 수 있는가?
4. **퇴사자 권한 회수 자동화**: 퇴사일 기준 D+1일이 되었을 때, 별도의 수작업이나 지시 없이도 시스템이 알아서 연동된 모든 사내 시스템의 계정을 차단 및 삭제하는가?
5. **권한 회수 검증 화면**: 시스템의 자동 회수 작업이 끝난 후, 담당자에게 누락 없이 "이 직원의 그룹웨어, ERP 권한이 정상적으로 모두 회수되었음"을 담당자가 직관적으로 체크하고 눈으로 검증할 수 있는 화면이 제공되는가?
6. **흐름의 완결성**: 이 화면 하나만 켜두면, 담당자가 더 이상 입사와 퇴사 처리를 위해 개별 시스템 관리자 페이지를 일일이 들락거릴 필요 없이 업무가 완전히 끝나는가?
