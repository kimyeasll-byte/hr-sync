# 4. 유저스토리 초안

1. **계정 자동 생성 스토리 (입사)**
   - **사용자**: 인사/전산 담당자
   - **목적**: 신규 입사자의 정보를 한 번만 입력하면, 여러 사내 시스템의 계정이 자동으로 생성되기를 원한다.
   - **이유**: 시스템마다 일일이 로그인해서 똑같은 계정 생성 작업을 반복하는 시간을 없애기 위해서이다.

2. **PC 세팅 자동화 스토리 (입사)**
   - **사용자**: 전산 담당자
   - **목적**: 초기화된 PC에 지시를 내리면 필수 프로그램 설치와 방화벽/네트워크 설정이 일괄적으로 자동 처리되기를 원한다.
   - **이유**: 자리에서 일일이 설치하고 네트워크를 잡는 귀찮고 긴 시간을 단축하기 위해서이다.

3. **퇴사자 권한 자동 회수 스토리 (퇴사)**
   - **사용자**: 보안/전산 담당자
   - **목적**: 사직서 결재 정보를 바탕으로 D+1일이 되면 퇴사자의 모든 시스템 권한이 자동으로 삭제되기를 원한다.
   - **이유**: 사람이 날짜를 깜빡해서 권한 회수를 누락하는 사고(ITGC 위반)를 근본적으로 막기 위해서이다.

4. **권한 회수 결과 검증 스토리 (퇴사)**
   - **사용자**: 보안/전산 담당자
   - **목적**: 권한 자동 삭제 작업이 끝난 후, 어떤 시스템에서 삭제가 성공했는지 한눈에 볼 수 있는 결과 리포트(체크리스트 화면)를 제공받기를 원한다.
   - **이유**: 시스템이 알아서 삭제 작업을 처리하더라도, 관리자로서 진짜로 모든 권한이 안전하게 회수되었는지 눈으로 직접 최종 검증을 해야 하기 때문이다.
