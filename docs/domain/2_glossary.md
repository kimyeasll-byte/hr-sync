# 2. 공통 용어집

- **입사 온보딩 / 입사 준비**: 신규 입사자가 합격 통보를 받은 후 출근하여 사원증과 장비를 모두 지급받고 정상적으로 업무를 시작할 수 있게 되기까지의 전체 과정.
- **입사 안내 메일**: 최종 합격자에게 출근 날짜와 시간 등을 안내하기 위해 발송하는 이메일.
- **여유 PC**: 퇴사자가 쓰던 PC나 창고에 보관 중인 재고 PC로, 지급 전 초기화(포맷)를 거치는 대상.
- **명함 정보 파서 문구점에 전달**: 이력서의 영문 이름 등을 활용해 명함에 들어갈 텍스트를 정리한 뒤 문구점에 제작을 요청하는 행위.
- **고정 IP 이더넷 설정**: PC 세팅 시 사내 네트워크 환경에 맞추어 수동으로 IP를 할당하는 작업.
- **사직서**: 퇴사 과정의 시작을 알리는 문서. 결재가 완료되어 담당자에게 전달됨.
- **D-day (퇴사일)**: 직원이 출근하는 마지막 날. 물리적 장비 반납이 이루어짐.
- **D+1**: 퇴사 다음 날. ITGC 규정에 따라 퇴사자의 모든 사내 시스템 권한을 회수하고 삭제해야 하는 기준일.
- **ITGC (정보기술일반통제)**: 기업의 IT 시스템에 대한 내부통제 규정으로, 보안을 위해 퇴사자의 권한을 신속히 회수하는 것이 중요한 감사 항목임.
