# 2. 화면 목록과 화면 정의서

## 1) 첫 화면 (대시보드)
- **화면 이름**: 첫 화면 (대시보드)
- **답하는 질문**: "오늘 내가 당장 해야 할 일은 무엇이고, 전체 일정은 어떻게 되는가?"
- **화면에 있는 것**: 
  - 달력 뷰 / 할 일 목록 뷰 전환 버튼
  - 입사 준비 및 퇴사 권한 회수 대기 목록
  - 작업 진행 중 상태 표시 (예: 작업 중 30%)
- **가장 크게 보일 행동**: 할 일 목록 중 하나를 클릭하여 세팅 화면으로 진입하기
- **다음 화면**: 입사자 세팅 화면

## 2) 입사자 세팅 화면
- **화면 이름**: 입사자 세팅 화면 (꽉 찬 화면)
- **답하는 질문**: "이 입사자에게 어떤 시스템 계정과 소프트웨어를 챙겨주어야 하는가?"
- **화면에 있는 것**: 
  - 입사자 기본 정보 입력란 (이름, 소속 등)
  - 설치할 필수 프로그램 및 권한 목록 (ERP, MES 등 체크박스)
- **가장 크게 보일 행동**: [입사 준비 완료 처리] 버튼
- **다음 화면**: 첫 화면 (버튼 클릭 시 즉시 빠져나옴)

## 3) 알림 및 오류 확인 패널
- **화면 이름**: 알림 패널
- **답하는 질문**: "내가 시스템에 맡겨둔 자동화 작업이 잘 끝났는가?"
- **화면에 있는 것**:
  - 성공 메시지 내역
  - 실패 메시지 (예: ERP 계정 생성 실패 내역)
- **가장 크게 보일 행동**: [ERP 관리자 페이지 열기] 버튼
- **다음 화면**: 외부 ERP 시스템 관리자 페이지
