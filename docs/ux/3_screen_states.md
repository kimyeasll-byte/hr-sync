# 3. 화면별 상태 정의

## 1) 비어 있을 때 (Empty State)
- **위치**: 첫 화면
- **보이는 것**: "현재 예정된 입사/퇴사 일정이 없습니다."라는 안심되는 문구와 부드러운 일러스트.
- **할 수 있는 행동**: [+ 수동으로 새 입사/퇴사 건 등록하기] 또는 [지나간 전체 이력 검색하기] 버튼을 통해 누락 건을 직접 등록하거나 이력을 조회할 수 있다.

## 2) 기다릴 때 (Wait State)
- **위치**: 첫 화면
- **보이는 것**: 입사자 세팅 화면에서 처리 버튼을 누르고 나왔을 때, 해당 할 일 항목 옆에 '작업 중(30%)' 텍스트와 진행률이 작게 나타난다. 화면 전체를 가리는 로딩 창은 없다.
- **할 수 있는 행동**: 시스템이 일하는 1~2분 동안 화면의 다른 메뉴를 누르며 다른 사원증 신청 등의 다중 작업(멀티태스킹)을 할 수 있다.

## 3) 잘 됐을 때 (Success State)
- **위치**: 첫 화면 / 알림 패널
- **보이는 것**: 작업이 성공적으로 모두 끝나면 "모든 권한이 정상적으로 회수(생성)되었습니다"라는 완료 알림이 나타난다.
- **할 수 있는 행동**: 알림을 확인하고 해당 건을 최종 종료 처리한다.

## 4) 잘못됐을 때 (Error State)
- **위치**: 알림 패널
- **보이는 것**: "그룹웨어는 성공했지만 ERP 계정 생성은 실패했습니다" 와 같이 어떤 시스템에서 꼬였는지 보여주는 구체적인 실패 내역.
- **할 수 있는 행동**: [ERP 관리자 페이지 열기] 버튼을 눌러 담당자가 즉각적으로 해당 관리자 창으로 이동해 수기로 해결한다.
