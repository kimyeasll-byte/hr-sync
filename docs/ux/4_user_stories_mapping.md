# 4. 유저스토리와 화면 연결표

| 유저스토리 | 연결된 화면 | 해결 방식 |
|---|---|---|
| **1. 계정 자동 생성 스토리 (입사)** | 입사자 세팅 화면 | 입사자 정보를 한 번 입력하고 [입사 준비 완료 처리] 버튼을 누르면 시스템이 계정을 일괄 자동 생성함. |
| **2. PC 세팅 자동화 스토리 (입사)** | 입사자 세팅 화면 | 동일 화면에서 프로그램 목록을 체크하고 처리 버튼을 누르면, 시스템이 알아서 네트워크 및 설치 세팅을 시작함. |
| **3. 퇴사자 권한 자동 회수 스토리 (퇴사)** | 첫 화면 (대시보드) | 첫 화면 달력이나 목록에 D+1일 일정이 뜨며, 시스템이 자동 회수한 뒤 결과를 알림으로 보고함. |
| **4. 권한 회수 결과 검증 스토리 (퇴사)** | 알림 패널 및 첫 화면 | 완료 알림을 통해 내 눈으로 직접 성공 여부를 확인하고, 실패 건이 있다면 [관리자 페이지 열기]를 눌러 검증 및 해결 조치를 함. |

*모든 도메인 유저스토리가 화면 동선에 누락 없이 연결되어 검증되었습니다.*
