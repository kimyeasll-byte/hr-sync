# 6. 다음 단계(UI/디자인)로 넘길 메모

- **비어 있을 때의 긍정적 분위기**: 일이 없는 텅 빈 대시보드가 에러창처럼 보이지 않도록 '안심되는 문구'와 함께 귀엽고 부드러운 일러스트를 활용해 담당자의 기분을 좋게 해주는 디자인을 고민할 것.
- **다크/라이트 모드 (시각적 피로도)**: 시스템 알림창을 띄워두고 멀티태스킹을 하므로, 다른 업무 화면(보통 하얀 엑셀이나 ERP 등)과 눈의 피로도가 섞이지 않게 다크/라이트 모드 선택이나 튀지 않는 색상을 고려할 것.
- **로딩 애니메이션 절대 금지**: 버튼을 눌렀을 때 화면 전체 중앙을 덮는 뱅글뱅글 도는 강제 로딩 모달 창은 **절대** 쓰지 말 것. 담당자의 다중 작업을 방해함. 할 일 리스트 구석에 작게 들어가는 진행률 텍스트(예: 작업 중 30%) 방식을 사용할 것.
- **버튼 문구 유지**: 화면 하단의 핵심 액션 버튼 이름은 개발적인 느낌을 주는 용어보다, 사용자에게 자신의 임무가 끝났다는 심리적 안도감을 주는 **[입사 준비 완료 처리]**라는 문구를 그대로 유지할 것.
