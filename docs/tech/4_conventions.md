# 4. 코딩 규칙 (Conventions)

1. **에러는 화면에서 바로 튕기지 말고 DB에 묻는다**
   - 백그라운드 작업 중 난 에러는 `try-catch`로 잡아 무조건 `logs` 테이블에 `is_success = false`로 저장한다. 그래야 알림 패널에 뜬다.
2. **날짜와 시간은 타임존(KST) 명시**
   - 인사 업무 특성상(퇴사일 D+1 계산 등) UTC 기준이 꼬이면 권한이 엉뚱한 날짜에 지워질 수 있으므로, 코드상 날짜 연산은 반드시 한국 시간(KST)을 기준으로 짠다.
3. **환경변수 이름 규칙**
   - 브라우저에 노출되어도 되는 값은 `NEXT_PUBLIC_` 접두사를 붙이고, ERP/그룹웨어 관리자용 비밀번호(API 키)는 절대 노출되지 않도록 `NEXT_PUBLIC_`을 붙이지 않는다.
