# [ADR 003] 개인정보 로그 보관 기간 결정

- **결정해야 했던 것**: 입퇴사자의 이름, 소속 및 권한 회수 이력 등 민감한 개인정보를 언제까지 DB에 보관할 것인가.
- **선택지**: (가) 1개월 보관, (나) 1년 보관, (다) 3년 보관, (라) 영구 보관
- **우리의 결정**: **(다) 내부 감사용으로 3년 보관 후 자동 삭제**
- **포기한 것**: 1달 뒤 바로 삭제하여 얻는 극단적인 DB 용량 절약과, 3년 이상 영구적으로 데이터를 조회할 권한.
- **다시 봐야 할 때**: 텍스트 데이터가 많아져서 Supabase 무료 DB 용량(500MB)에 한계가 오거나, 회사 내부 규정이 바뀌어 즉각 삭제가 법적으로 강제될 때.
