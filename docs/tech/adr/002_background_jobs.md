# [ADR 002] 오래 걸리는 일(비동기 처리) 방식 결정

- **결정해야 했던 것**: 1~2분씩 걸리는 계정 세팅 및 권한 회수 작업이 서버 무료 제한(10초)에 걸려 끊기는 현상을 어떻게 막을 것인가.
- **선택지**: (가) 직접 폴링(Polling) 구현, (나) Upstash QStash 비동기 큐 사용
- **우리의 결정**: **(나) Upstash QStash 사용**
- **포기한 것**: 단일 서버 환경 안에서만 빙글빙글 돌아가는 가장 단순하고 고전적인 구조.
- **다시 봐야 할 때**: 일일 입퇴사자가 하루에 수백 명씩 쏟아져서 Upstash 무료 호출 건수(일 500회)를 초과하게 될 때.
