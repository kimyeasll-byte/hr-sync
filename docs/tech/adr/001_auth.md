# [ADR 001] 로그인 및 보안 방식 결정

- **결정해야 했던 것**: 민감한 인사 데이터를 보호하기 위해 시스템 접근 권한(로그인)을 어떻게 통제할 것인가.
- **선택지**: (가) 다우오피스 유료 연동, (나) 무료 매직 링크(사내 도메인) + 관리자 승인, (다) 하드코딩된 이메일 명단
- **우리의 결정**: **(나) 이메일 매직 링크 가입 + 최고 관리자 수동 승인 방식**
- **이유**: 일반 직원이 `@gopowernet.com`으로 접속하더라도 인사팀 담당자(총 4명)가 아니면 내용을 볼 수 없도록, 가입 후 기획자님이 이메일을 보고 직접 승인해 줘야만 화면이 열리도록 완벽하게 통제합니다.
- **포기한 것**: 누구나 가입 즉시 사용할 수 있는 개방성과, 별도의 승인 관리 기능(버튼)을 안 만들어도 되는 극단적인 단순함.
- **다시 봐야 할 때**: 인사팀이 수십 명으로 늘어나서 일일이 승인해주기 귀찮아지거나, 전사 직원이 모두 써야 하는 시스템으로 사용 범위를 확대할 때.
