# 6. 선택 기록 (디자인 워크숍)

- **0라운드 (레퍼런스)**: (다) 버셀 스타일 기반에 애플의 모던/심플함 추가
  - 이유: 신뢰감 있는 자동화 시스템의 동선이 마음에 들고, 미적으로는 애플처럼 깨끗하기를 원하심.
- **1라운드 (전체 인상)**: (가) 차분하고 정돈된 '전문가용 도구' 느낌
  - 이유: 업무의 정확성과 신뢰감을 주는 차분한 인상을 선호하심.
- **2라운드 (화면 밀도)**: (나) 숨 쉴 틈을 적당히 두는 중간 방식
  - 이유: 정보가 답답하지 않고 눈이 편안한 여백과 심플함을 선호하심.
- **3라운드 (기준색)**: 검정색 버튼 (1차 흑백 프리뷰 캡처를 본 뒤 확정)
  - 이유: 시크하고 깔끔한 명도 대비가 주는 세련됨에 만족하심.
- **4라운드 (테마)**: (다) 시스템 설정에 따라 알아서 바뀌는 방식
  - 이유: 업무 시간에 구애받지 않고 눈이 편안하길 원하심.
- **5라운드 (의미색)**: (가) 애플 기본 신호등 방식
  - 이유: 1초 만에 상태를 직관적으로 파악할 수 있어 편하기 때문.
- **6라운드 (글자)**: (가) 제목은 확연히 크고 굵게, 본문은 차분하게 (대비가 강한 방식)
  - 이유: 1차 프리뷰 이미지의 시원한 뷰를 마음에 들어하셨음.
- **7라운드 (형태)**: (가) 12px 둥글기 + 아주 옅은 테두리와 그림자
  - 이유: 튀지 않고 단정하며 가장 모던한 애플 표준 형태를 선호하심.
- **8라운드 (간격)**: (가) 4px 단위 시스템
  - 이유: 촘촘하고 세밀하게 조율하여 PC 화면에 맞게 꼼꼼히 배치하기 위함.
- **9라운드 (부품)**: (가) 쫀쫀하게 눌리는 반응 방식 (Scale down)
  - 이유: 누르는 재미와 명확한 햅틱/시각적 피드백으로 반복 업무의 피로도를 낮추기 위함.
- **10라운드 (아이콘)**: (가) 선이 얇은 아이콘 + '아이콘만 있는 버튼' 절대 금지
  - 이유: 모호함을 없애고 누구든 의미를 절대 헷갈리지 않는 명확성을 중시하심.
