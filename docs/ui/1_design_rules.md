# 1. 디자인 규칙 문서

1. **전체 인상**: 차분하고 정돈된 '전문가용 도구' (Mac OS 스타일)
   - 이유: 업무의 정확성과 신뢰감을 주는 차분한 느낌을 선호하심.
2. **화면 밀도**: 숨 쉴 틈을 적당히 두는 중간 방식
   - 이유: 정보가 빽빽하지 않고 눈이 편안한 여백과 심플함을 선호하심.
3. **기준색**: 깊은 검정색 (Black)
   - 이유: 시크하고 깔끔한 명도 대비가 주는 세련됨에 만족하심.
4. **바탕색과 글자색**: 시스템 설정에 따라 알아서 바뀌는 모드 (Auto Light/Dark)
   - 이유: 낮과 밤 업무 환경에 맞춰 눈의 피로도를 최소화하기 위함.
5. **의미를 가진 색**: 애플 기본 신호등 방식 (성공: 초록, 에러: 빨강, 진행: 파랑)
   - 이유: 1초 만에 직관적으로 상태를 파악하여 인지 피로도를 줄이기 위함.
6. **글자**: 제목은 아주 크고 굵게, 본문은 작게 (대비가 강한 방식)
   - 이유: 영역 구분을 확연히 하여 시원한 뷰를 원하심.
7. **형태**: 적당한 둥글기(12px)와 아주 옅은 테두리 및 그림자 방식
   - 이유: 가장 표준적인 애플 스타일로 단정함을 살림.
8. **간격**: 4px 단위 방식
   - 이유: PC 모니터용 업무 시스템을 정교하고 세밀하게 조율하기 위함.
9. **부품 반응**: 쫀쫀하게 눌리는 크기 변화 방식 (Scale down)
   - 이유: 클릭 피드백이 명확하여 반복 작업의 지루함을 덜어줌.
10. **아이콘 규칙**: 선이 얇은 아이콘(1.5px) + 항상 글자와 함께 쓰기
    - 이유: 누구든 절대 버튼의 의미를 헷갈리지 않게 명확히 하기 위함.
