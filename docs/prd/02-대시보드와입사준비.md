# 02. 대시보드 진입 및 신규 입사자 세팅 요청

- **할 일**: 승인받은 담당자가 대시보드에서 신규 입사자의 기본 정보를 적어 내고, 시스템이 이를 기억하게 한다.
- **확인 문장**:
  - 화면에 디자인 규칙(오토 다크모드, 12px 둥근 카드 등)이 입혀진 빈 대시보드가 뜬다.
  - 신규 입사자 이름, 소속, 출근 예정일을 적는 칸이 있다.
  - 내용 없이 버튼을 누르면 "이름을 입력하세요" 등 빨간색 경고가 화면에 뜬다.
  - [입사 세팅하기] 버튼을 누르면 버튼이 쫀쫀하게 눌리는 애니메이션이 작동한다.
  - 제출 직후, 카드의 상태가 파란색 "작업 중" 배지로 바뀌며, 마우스가 멈추거나 화면이 굳지 않는다.
- **이번에 안 할 것**: 제출된 정보를 가지고 진짜 ERP나 그룹웨어 서버에 통신을 보내 계정을 뚫는 작업. (다음 조각에서 진행)
- **바뀐 것**: (아직 없음)
