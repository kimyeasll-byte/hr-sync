# 01. 로그인 및 담당자 가입 승인

- **할 일**: 담당자가 회사 이메일(@gopowernet.com)로 매직 링크를 받아 로그인하고, 기획자의 승인을 받아야만 화면에 들어갈 수 있게 한다.
- **확인 문장**:
  - 회사 이메일을 치고 버튼을 누르면 내 메일함에 접속 링크가 도착한다.
  - 다른 도메인 이메일을 치면 "가입할 수 없는 이메일"이라고 화면에 뜬다.
  - 가입은 했지만 아직 승인되지 않은 상태로 들어오면 "최고 관리자 승인 대기 중입니다"라는 안내 글자만 보이고 다른 버튼은 아무것도 안 보인다.
  - 승인이 완료된 후 다시 접속하면 정상적으로 [오늘의 할 일] 대시보드가 보인다.
- **이번에 안 할 것**: 다우오피스 비밀번호 직접 연동, 복잡하고 화려한 로그인 화면 디자인, **별도의 '최고 관리자 승인용 화면' 만들기 (기획자가 직접 DB에 접속해 승인 처리함)**.
- **바뀐 것**: 
  - 2026-09-24: 관리자 승인 화면을 따로 만들지 않고, MVP 단계에서는 DB(Supabase)에서 직접 승인 체크박스를 켜주기로 확정.
