# HR Sync 프로젝트 개발 요약본 (기획자 공부용)

이 문서는 IT 지식이 깊지 않은 기획자라도 우리가 지금까지 어떤 과정을 거쳐 앱을 만들었는지 쉽게 이해할 수 있도록 정리한 요약본입니다.

## 1. 우리가 만든 것 (전체 그림)
인사팀이 신규 입사자나 퇴사자가 발생했을 때, 그룹웨어와 ERP 계정을 자동으로 세팅하고 회수하는 **[HR Sync]**라는 사내 자동화 시스템의 뼈대(MVP)를 만들었습니다.

## 2. 우리가 지나온 핵심 단계들

### 1단계: 껍데기(UI) 만들기
- **디자인 입히기:** 최신 기술인 Tailwind CSS를 사용해 애플(Apple) 스타일의 깔끔하고 직관적인 대시보드 화면을 그렸습니다.
- **편의성 추가:** 퇴사자를 실수로 잘못 지우지 않도록, 이름을 '검색'해서 클릭하게 만드는 자동완성 기능을 추가했습니다. (휴먼 에러 방지)

### 2단계: 뇌와 기억력(DB) 붙이기 - Supabase
- 데이터를 영구적으로 저장하기 위해 **Supabase(수파베이스)**라는 클라우드 데이터베이스를 연결했습니다.
- 입사자 명단(`employees`), 작업 내역(`tasks`), 감사 로그(`logs`), 관리자 명단(`admin_users`)을 담을 엑셀 표(테이블)를 만들었습니다.
- **실시간 통신:** 작업이 완료되면 새로고침 없이 화면의 게이지가 30%에서 100%로 쓱! 바뀌도록 만들었습니다.

### 3단계: 우리 집 문 잠그기 - 보안 인증
- 아무나 들어오면 안 되기 때문에 `@gopowernet.com` 이메일만 접속할 수 있게 막았습니다.
- **매직 링크 (Magic Link):** 비밀번호를 외울 필요 없이, 이메일로 온 링크만 누르면 로그인되는 최신 방식을 적용했습니다.
- **관리자 승인:** 처음 로그인한 사람은 무조건 '대기' 상태로 두고, DB에서 관리자가 `TRUE`로 바꿔줘야만 메일이 날아가도록 이중 보안을 걸었습니다.

### 4단계: 인터넷 세상에 런칭하기
- **Git (깃):** 내 컴퓨터에만 있던 코드를 인터넷 창고(GitHub)에 안전하게 백업했습니다.
- **Vercel (버셀):** 깃허브에 있는 코드를 가져다가, 전 세계 누구나 스마트폰으로도 접속할 수 있게 24시간 돌아가는 진짜 인터넷 서버(도메인)를 만들어주고 있습니다.

---

## 3. 핵심 IT 용어 쉬운 풀이
- **프론트엔드 (Next.js):** 사용자가 보는 화면과 버튼을 만드는 기술. 우리 프로젝트의 얼굴입니다.
- **백엔드/DB (Supabase):** 데이터를 저장하고 로그인 보안을 책임지는 보이지 않는 창고입니다.
- **Git / GitHub:** 게임의 '세이브 포인트' 같은 곳입니다. 코드를 날려먹어도 언제든 과거로 돌아갈 수 있게 해줍니다.
- **Vercel (버셀):** 우리가 만든 앱을 인터넷에 띄워주는 호스팅 서비스입니다. "건물을 올릴 땅과 주소"를 빌려준다고 생각하면 됩니다.
- **환경변수 (Environment Variables):** 소스코드에 대놓고 쓰면 해커들이 훔쳐 가는 'DB 비밀번호' 같은 것들을 안전하게 숨겨두는 금고입니다. 아까 Vercel에 3줄 복사해서 넣으신 게 바로 이 금고 채우기 작업이었습니다.

## 4. 앞으로 남은 것
이제 인터넷에 주소(URL)가 생기면, 임시로 만들어둔 '3초 타이머' 대신 **QStash**라는 진짜 우체부(비동기 백그라운드 큐)를 달아줄 예정입니다. 그러면 시스템이 멈추지 않고 진짜로 완벽하게 자동화됩니다!
